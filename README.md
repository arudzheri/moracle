# moracle 🧪🔮
Molecule oracle for predicting clinical viability from binding affinity and historical clinical trial data.

Project for the EF-Valence Labs Bio x AI Hackathon. Awarded second place.

## My contribution
I worked on: Mainly to the data and modeling side of the project. I built the pipeline that connects binding‑affinity predictions with clinical‑trial history, making it possible for the system to estimate whether a molecule is likely to succeed beyond pre‑clinical stages.
